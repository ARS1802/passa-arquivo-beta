Passa Arquivo API

API HTTP para compartilhar arquivos usando JSON e conteúdo em Base64.

Base URL: http://<ip-da-maquina>:3000

Upload

POST /files/upload

Envie um corpo JSON com o nome, o tipo MIME e o conteúdo do arquivo:

{
  "filename": "documento.pdf",
  "mimeType": "application/pdf",
  "data": "<conteudo-em-base64>"
}

Resposta de sucesso (201 Created):

{
  "filename": "documento.pdf",
  "mimeType": "application/pdf",
  "size": 12345,
  "downloadUrl": "/files/download/documento.pdf"
}

O tamanho máximo é 100 MiB. Arquivos existentes não são sobrescritos.

Possíveis erros: 400 (dados inválidos), 409 (arquivo existente) e 413 (arquivo grande).

Download

GET /files/download/:filename

Substitua :filename pelo nome do arquivo:

GET /files/download/documento.pdf

Resposta de sucesso (200 OK):

{
  "filename": "documento.pdf",
  "mimeType": "application/octet-stream",
  "data": "<conteudo-em-base64>",
  "size": 12345
}

Possíveis erros: 400 (nome inválido) e 404 (arquivo não encontrado).

Listagem

GET /files

Retorna os arquivos disponíveis:

{
  "files": [
    {
      "filename": "documento.pdf",
      "mimeType": "application/octet-stream",
      "size": 12345,
      "lastModified": "2026-11-03T10:00:00.000Z"
    }
  ]
}

Regras gerais

Nome do arquivo
Deve começar com uma letra ou número e conter apenas letras, números, ponto, hífen ou sublinhado.
Conteúdo
O campo data deve ser uma string Base64 válida.
Content-Type
Requisições de upload devem usar application/json.
